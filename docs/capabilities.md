## 对大学生求职的帮助

Waynex 主要减少求职过程中的信息查找、初步比较和个人记录工作，把原本散在网站、公众号、聊天记录与表格里的步骤接到一起。

| 求职环节 | 当前能够提供的支持 | 仍需学生完成的事 |
| --- | --- | --- |
| 发现机会 | 汇集已收录的公开招聘项目，集中浏览与搜索 | 结合目标方向判断，并补充查看尚未收录的来源 |
| 初步筛选 | 按届次、地点、学历、行业、性质筛选和比较，查看截止信息 | 核对具体岗位的专业、资格、职责和特殊限制 |
| 准备投递 | 提供可用的公告链接、投递渠道或报名说明 | 准备简历与材料，在指定渠道完成提交 |
| 线下求职 | 查看校园招聘会与企业宣讲，关注活动并整理个人日历 | 确认参加资格、报名、行程和临时变更 |
| 持续跟进 | 看板或表格查看项目进度，手动维护阶段和备注 | 查看企业通知，更新状态，准备笔试与面试 |
| 跨端使用 | 同账号读取已保存的个人数据与活动关注 | 确认修改已保存成功，必要时刷新另一设备 |

因此，Waynex 可以帮助学生建立一份可浏览、可筛选、可行动、可跟进的求职清单，减少反复切换平台和重复整理信息。它提供求职过程中的信息与管理支持，录用仍取决于岗位要求、个人准备和招聘单位的选择。

## 三个主要模块

### 招聘信息

- 搜索单位、岗位或城市。
- 按毕业届次、工作地点、学历、行业与企业性质筛选，地点、行业和性质支持多选。
- 使用最新招聘、往届可投、央国企优选、外企精选、互联网和金融快捷分类。
- 按最新更新或即将截止排序。
- 在列表查看招聘项目概况，打开可用的原始公告、投递渠道或报名说明。
- 在招聘列表直接记录个人进度。

### 校园活动

- 浏览招聘会、企业宣讲和其他就业活动。
- 按活动类型、举办高校、省份和时间查找，查看活动详情及公告。
- 有可靠数据时展示参会单位、岗位及相关安排，字段缺失时不补造。
- 登录后关注活动，通过“我的关注”和个人活动日历管理已关注内容。

### 求职进度

- 按招聘项目记录待投递、已投递、笔试、一面、二面、更多面、已 Offer、未通过八种阶段。
- 使用看板或表格视图，编辑个人备注、调整排列或取消标记。
- 与招聘列表中的个人阶段共用记录。
- 同一账号在电脑和手机网页读取已保存的数据。

## 信息从哪里来

项目的信息整理覆盖公众号文章、高校就业平台、企业官网及官方招聘渠道。采集与整理帮助提取公告内容、招聘条件、投递方式和活动安排；自动处理结果仍需核对，采集能力不等于所有来源均已完整接入或实时更新。

整理时保留原始来源与可用链接，方便学生核对。没有可靠依据的专业、学历、地点或截止时间不作推断，也不将未知信息写成“不限”。一个招聘项目可能包含多个岗位，项目级概况不意味着每个岗位都具有相同条件。

## 当前使用边界

- **覆盖范围**：不保证全网收录，也不保证所有企业和高校都有数据；不以固定数字承诺覆盖规模或更新频率。
- **投递与结果**：不代投简历，不自动判定外部提交成功，不保证面试或录用；企业通知以其官方渠道为准。
- **进度粒度**：当前为项目级个人记录，多个岗位不分别维护独立进度；个人阶段由学生确认和更新。
- **活动与提醒**：关注活动不等于报名或开启提醒；自动提醒、系统日历导出与日程冲突检测不在当前能力介绍内。
- **智能服务**：AI 个性化推荐、求职助手、简历优化与自动投递不作为现有服务宣传。
- **客户端**：当前使用电脑网页和手机 H5，不将小程序或原生 App 写成已有客户端。
- **招聘详情**：学生端招聘详情抽屉当前关闭；可以通过招聘列表中的公告和投递入口核对信息，校园活动详情仍可查看。
