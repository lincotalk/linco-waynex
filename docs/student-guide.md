# 学生使用指南

**使用入口：[https://waynex.lincolab.com/](https://waynex.lincolab.com/)**

[返回 README](../README.md) · [产品能力与边界](capabilities.md)

## 先找到一批值得看的机会

打开招聘信息页，搜索你关心的单位、岗位或城市，再按毕业届次、工作地点、学历、行业和企业性质缩小范围。地点、行业和性质支持多选；条件不确定时，可以先放宽筛选。

例如，你正在准备某一届秋招，希望在几个目标城市找工作，可以先选择自己的毕业届次和目标地点，再搜索岗位方向；如果暂时没有目标企业，可以先浏览“央国企优选”“外企精选”“互联网”或“金融”等分类。

列表可以帮助你比较单位、届次、地点、岗位、学历和截止信息。想先看新机会，使用“最新更新”；想优先检查时间紧的机会，使用“即将截止”。排序用于安排查看顺序，能否投递仍需核对原始公告。

## 核对条件，再去投递

打开项目对应的“校招公告”，重点检查：

- 毕业届次、学历、专业及其他资格要求。
- 具体岗位职责、工作地点和所需材料。
- 报名开始与截止时间，是否分岗位或分批次。
- 投递方式、招聘流程以及后续通知渠道。

有“投递渠道”的项目，可通过该入口前往招聘单位的申请渠道；显示“报名说明”时，先查看公告里的申请步骤，可能需要邮件、现场或其他方式。入口缺失时，请从原始公告核对，不能把项目已收录理解为可以直接网申。

Waynex 展示的是整理后的信息。某个字段为空，表示当前没有可靠信息，不代表条件不限；列表上的项目概况也不能代替具体岗位要求。

## 用求职进度记录下一步

登录后，你可以在招聘信息页选择“我的进度”，再到 [求职进度](https://waynex.lincolab.com/me) 集中查看。

| 阶段 | 适合记录的情况 |
| --- | --- |
| 待投递 | 有兴趣，准备核对条件或整理材料 |
| 已投递 | 已经在招聘单位要求的渠道完成提交，并由自己确认 |
| 笔试 | 进入笔试阶段 |
| 一面 / 二面 / 更多面 | 进入相应面试阶段 |
| 已 Offer | 已收到 Offer |
| 未通过 | 已确认该项目本次申请未通过 |

可以选择看板或表格视图。备注适合记录具体岗位、企业通知、时间和下一步待办，例如“周五前补交成绩单”或“已约下周二面试”。备注中的日期属于个人记录，不会自动生成提醒。

当前进度按招聘项目记录。如果同一项目投了多个岗位，可以先在备注中分别记下，系统暂不为每个岗位建立独立进度。

**取消标记会删除该项目的进度记录和备注。** 如果只是推进或调整阶段，请改选阶段；取消标记不会撤回企业系统中的申请。

## 把校园活动放进自己的日程

打开 [校园活动](https://waynex.lincolab.com/campus)，浏览招聘会、企业宣讲和其他就业活动。可以按举办高校、省份和活动时间筛选，也可以搜索活动。

查看活动详情时，如页面提示登录，请先完成登录，再核对时间、地点、参与方式及完整公告；有参会名单时，可以查看已收录的单位。没有名单表示尚未提供或整理，不代表没有企业参加。

登录后，点击关注图标保存感兴趣的活动：

- 在“我的关注”中集中查看。
- 在个人活动日历中查看有明确日期的活动。
- 手机或较窄屏幕可通过“我的日程”打开日历。

列表筛选不会改变个人日历。没有明确日期的活动可在“我的关注”中核对；关注只用于保存和整理活动，报名仍按活动公告要求完成。

## 电脑整理，手机继续查看

同一账号可在电脑与手机网页读取已成功保存的个人资料、求职进度、备注和活动关注。另一设备需要时可刷新页面读取最新内容。

如果保存失败，请保留填写内容，检查网络和登录状态后重试；尚未成功保存的修改不会同步。本机搜索历史也不会跨设备同步。

遇到信息错误或使用问题，可在 [帮助中心](https://waynex.lincolab.com/help) 提交反馈，附上相关公告链接和问题描述，便于定位。
